# micro:bit Practice Lab

A picture-book style page for parents with no computer background. It explains the micro:bit chapter of the school computer book one small idea at a time, with huge text, a big Next button, and something to tap on almost every screen.

Lessons:
1. Meet the micro:bit (what it is, buttons, lights, blocks)
2. Counting (book page 112: variables)
3. Happy or sad face (book page 110: if / else)
4. Flashing arrow ("Now try this": loops)

Live at https://sv62.github.io/microbit-practice/ once GitHub Pages is on (Settings → Pages → Deploy from branch → main / root).
