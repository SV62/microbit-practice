# micro:bit Practice Lab

A one-page practice site for the "Computational thinking and programming" chapter. It covers three programs from the textbook: a Count variable (button A), if/else with a shake gesture, and a repeat loop that flashes an arrow (button B). Each one runs on a pretend micro:bit, so no real micro:bit is needed.

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
