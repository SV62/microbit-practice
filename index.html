micro:bit Practice Lab

This page explains the three programs in your child's computer book, in simple words. You don't need to know anything about computers to use it.

What is a micro:bit?

It is a very small computer, about the size of a bank card. It has 2 buttons (called A and B) and 25 tiny red lights that can show numbers and pictures.

Children tell it what to do by joining coloured blocks together, a bit like LEGO. Each block is one instruction. This is called a program.

How to use this page

  1. Pick a lesson using the three big buttons below. They match the pages in the book.
  2. Tap the A or B button on the pretend micro:bit (the black board).
  3. Watch the lights change. A yellow line appears around the block that is working at that moment.
  4. Answer the questions at the bottom. They are like the ones in the book.

Book words in simple English

InputWhat goes in. The micro:bit notices you pressing a button or shaking it.
OutputWhat comes out. The lights show a number or a face.
VariableA box with a name that keeps a number, like a score in a game. The number can change.
Selection (if / else)Making a choice. If something is true, do this. Otherwise (else), do that.
Iteration (loop)Doing the same thing again and again, like "clap 4 times".
EventWaiting for something to happen, like a doorbell waiting to be pressed.
Lesson 1 · Book page 112 · Topic: variables

Counting how many times button A is pressed

Think of a cricket scoreboard. It starts at 0, and every time a run is scored, the number goes up by one. This program does the same thing with button A.

The code, as it looks in the book
on start
set Count to 0 show number Count
forever
if button A is pressed then
set Count to Count + 1 show number Count
Pretend micro:bit

Tap the A button on the left of the board a few times

Count0

The micro:bit is switched on, so Count starts at 0. Now tap button A.

What the blocks say, in plain English

  1. on start When the micro:bit is switched on, do these things once:
  2. set Count to 0 Make a box called "Count" and put 0 in it.
  3. show number Count Show that number on the lights.
  4. forever Then keep doing the next part again and again, without stopping:
  5. if button A is pressed Is someone pressing button A? If yes:
  6. set Count to Count + 1 Add 1 to the number in the box.
  7. show number Count Show the new number.

Try this

  • Tap A three times. You should see 3. That is the answer to question 4 in the book.
  • Tap B. Nothing happens, because the program only looks at button A.
  • Tap the Unplug battery button, then plug it back in. The number goes back to 0. The program is still saved inside, but it starts again from the beginning.

The word variable just means a box with a name that holds a number that can change. Here the box is called Count.

Lesson 2 · Book page 110 · Topic: selection (if / else)

Shake it and it looks sad. Leave it and it looks happy

The program asks one yes-or-no question again and again: "Is someone shaking me?" If the answer is yes, it shows a sad face. If the answer is no, it shows a happy face.

The code, as it looks in the book
forever
if is shake gesture then
show icon
else
show icon
Pretend micro:bit

Tap the blue "Shake it" button under the board

Is it being shaken? NO

Not being shaken, so the else part runs and shows a happy face.

What the blocks say, in plain English

  1. forever Keep checking again and again, without stopping.
  2. if is shake gesture then Ask: is someone shaking me? If yes:
  3. show icon (sad) Show a sad face.
  4. else If the answer is no:
  5. show icon (happy) Show a happy face.

Try this

  • Tap Shake it. The board wobbles and the face turns sad. The yellow line moves to the top part of the code.
  • Wait a moment. The shaking stops, the answer becomes "no", and the happy face comes back.

An everyday example: "If it is raining, take an umbrella. Else (otherwise), take sunglasses." You only do one of the two. The book calls this selection, because the computer selects (chooses) what to do.

The book also uses the words True (means yes) and False (means no).

Lesson 3 · "Now try this" page · Topic: loops (iteration)

Press B and the arrow flashes 4 times

Instead of writing the same instructions 4 times, the program says "repeat 4 times". Each time, it shows the arrow, waits a moment, turns the lights off and waits again. That's what makes it flash.

The code, as it looks in the book
on button B pressed
repeat 4 times
show leds pause (ms) 200 clear screen pause (ms) 200
Pretend micro:bit

Tap the B button on the right of the board

Waiting for button B

Nothing happens until you tap B. The program is waiting, like a doorbell.

What the blocks say, in plain English

  1. on button B pressed Wait until someone presses button B. Then:
  2. repeat 4 times Do the next 4 steps, 4 times over:
  3. show leds Light up the arrow picture.
  4. pause (ms) 200 Wait a moment. 200 ms means a fifth of a second.
  5. clear screen Turn all the lights off.
  6. pause (ms) 200 Wait a moment again.

Try this

  • Tap B and count the flashes. You should count 4.
  • Tick Slow motion to see each step clearly.
  • Change the number 4 to 2 or 7, then tap B again. It flashes that many times.
  • Tap A. Nothing happens, because the program only waits for B.

An everyday example: instead of saying "clap, clap, clap, clap", you say "clap 4 times". The book calls this a loop or iteration.
